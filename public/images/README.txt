==================================================
KAVI GAURAV SAKSHI - DEMO IMAGES GUIDE
==================================================

All website images are located right here in this folder:
/public/images/

To customize the website with your own photos:
Simply paste your photos into this folder with these exact filenames:

1. poet-profile.jpg
   -> Main portrait photo of Kavi Gaurav Sakshi
   -> Used on the Homepage About Card and the Biography Page

2. stage-hero.jpg
   -> Wide stage/performance photo
   -> Used as the hero stage banner and poster

3. stage-1.jpg, stage-2.jpg, stage-3.jpg, stage-4.jpg
   -> Stage performance highlights
   -> Used in the Events & Shows photo gallery

4. video-thumb-1.jpg, video-thumb-2.jpg, video-thumb-3.jpg
   -> Video performance thumbnails (Sahitya Tak, Kavi Sammelans)

NOTE:
- Supported formats: .jpg / .jpeg / .png / .webp
- If you use the same filenames, NO CODE CHANGES ARE NEEDED! Just refresh the browser.
- You can also update the image paths in: src/data/poetData.js (under the `images` object).
